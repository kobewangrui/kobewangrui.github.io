# 王睿龙 · 在线简历

- 网页版：https://kobewangrui.github.io
- 投递版：[王睿龙-Web前端工程师.pdf](./王睿龙-Web前端工程师.pdf)

网页按个人信息、教育背景、核心技能、工作经历的顺序排版。工作经历用独立日期列和竖向时间轴呈现，窄屏下日期移动到各段经历上方。PDF 从同一份网页生成，使用静态极光页眉和同系配色，打印时收紧留白并隐藏下载入口。

## 更新内容和导出

1. 在 `index.html` 中更新简历文字和联系方式。
2. 页面与打印样式均在 `css/style.css`，屏幕版的极光动画和打印版的静态渐变均由 CSS 绘制。可直接在浏览器打开网页预览，无需构建。
3. 在 Chrome 或 Edge 中打印，选择「另存为 PDF」，纸张选 A4，缩放设为 100%，关闭页眉和页脚并勾选「背景图形」。样式已设置零页边距。
4. 确认打印预览仍为一页、最后一段完整可见，再保存为 `王睿龙-Web前端工程师.pdf`。发布时更新 `index.html` 中 PDF 下载链接的 `v` 参数；如果修改了样式，也更新样式链接的 `v` 参数，避免浏览器继续使用缓存。加长内容后，优先精简重复文字，不要用固定高度隐藏溢出。
